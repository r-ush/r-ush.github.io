Privacy & analytics

This site uses a public MapMyVisitors counter and a separate private aggregate collector to understand which research pages are useful and improve their presentation.

What the statistics contain

Daily page views, broad referral categories, country and administrative-region codes, device/browser/operating-system categories, link and download clicks, scroll milestones, section opens, deliberate video playback, estimated active reading time, and page-load timings.

The collector immediately adds these measurements to separate daily totals and, for the public map below, to country page-view counts in 10-minute intervals. It does not store raw event histories, visitor or session IDs, IP addresses, full user-agent strings, precise locations, search terms, query strings, email addresses, or cross-page journeys. Statistics do not count unique people or returning visitors. Daily aggregates are retained for up to 180 days and map intervals for at most two days. For the public map, all-time page-view totals per country (a country code and a count, without dates) are kept.

Public visitor map

The homepage's “Visitors around the world” map is public. Each dot is a country; its size combines Google Search Console search clicks with all of this site's collected page views from that country. A dot pulses when a page view from that country arrived within the last hour. The map has no region, city, coordinates, page, IP address or visitor identifier, but a single view from a country with few visitors is still visible as one visit. Opening the map loads these totals from the collector; that request is not counted.

Public visitor counter

MapMyVisitors receives an image request when you view a page, independently of our private collector. This request exposes network information such as your IP address to that provider for visitor counting and approximate geolocation. See the public visitor statistics and MapMyVisitors privacy policy. Our private collector's storage and retention limits described above do not govern this external service.

Your choice

Both counters respect Global Privacy Control and Do Not Track signals. You can also exclude this browser below. This preference is shared by pages on r-ush.github.io and is useful for excluding your own visits.

Infrastructure and external links

GitHub Pages serves this website. When the collector is enabled, Cloudflare Workers and D1 receive and aggregate measurements. Their infrastructure necessarily handles network information to deliver requests; this site's analytics code does not persist the IP address and disables Worker application logs. Hosting providers may maintain their own security or operational records. External sites and embedded services have their own privacy practices.
